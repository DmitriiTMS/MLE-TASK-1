# Текстовый квест "Таинственный лес"
Консольное приложение на TypeScript, реализующее текстовый квест с использованием паттернов MVC, State и Command.

## Установка и запуск
1. Клонируйте репозиторий
2. Установите зависимости: npm install
3. Сделайте сборку проекта: npm run build
4. Запустите проект: npm run start

## Запуск тестов: npm run test
